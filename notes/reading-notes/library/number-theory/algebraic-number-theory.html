Reading guide

Editorial orientation · optional routes Reviewed 2026-10-11

Begin with number fields, rings of integers and ideals, then valuations and completions. Keep local and global statements distinct.

Branches to choose from

  • Number fields
  • local fields / ramification
  • class field theory
  • arithmetic duality
  • p-adic differential / cohomological methods

How to continue

Local class field theory needs group cohomology; advanced p-adic geometry needs additional geometric foundations. A general arithmetic reference is not automatically the best first local-field course.
