Reading guide

Editorial orientation · optional routes Reviewed 2026-10-11

Learn ordinals, cardinals and the ZFC framework before treating a consistency result as a statement true in every model.

Branches to choose from

  • Axiomatic foundations
  • constructibility
  • forcing
  • large cardinals
  • descriptive set theory

How to continue

Forcing / large cardinals and descriptive-set methods are different advanced routes. Borel-set texts need topology and measure; forcing texts need model and ordinal foundations.
