Studying Measure & Integration

What to work on

  • Check measurability through inverse images.
  • Construct integrals from nonnegative simple functions.
  • Choose an applicable convergence theorem and verify its hypotheses.
  • Distinguish Tonelli's nonnegativity condition from Fubini's integrability condition.

A starting text

Measure, Integration & Real Analysis — Sheldon Axler. Read 2B-2C on measurable spaces and measures, 3A-3B on integration and convergence, then 5B on iterated integrals. Consult 2D only when the construction of Lebesgue measure is the gap.

Practice

Measurability, convergence and iterated-integral exercises. Exercises 2B, 2C, 3A, 3B and 5B, immediately following the named sections.. Exercises provided; public solutions not verified.

Try these before moving on

  • On (0,1) with Lebesgue measure let f_n = n times the indicator of (0,1/n). Find the pointwise limit and each integral; prove that no single integrable function dominates all f_n.
  • Compute the integral of exp(-x-y) over 0 < x < y < infinity in both orders, stating which theorem permits the exchange.

Already comfortable with this? Skip this review if you can justify both checks and verify monotone or dominated convergence in a new example. Review measurable-space definitions separately if you know integration formulas but cannot prove a function measurable.
