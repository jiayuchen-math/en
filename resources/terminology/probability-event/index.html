随机事件

Probability · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: 事件

Translation evidence: Literature usage

Meaning in context

A member AAA of the sigma-algebra F\mathcal FF in a probability space, so that P(A)P(A)P(A) is defined.

概率空间中属于指定事件σ代数的集合，因而其概率有定义。

Example

On a die space, {2,4,6}\{2,4,6\}{2,4,6} is the event of an even result.

Usage and distinctions

An arbitrary subset need not be an event on an uncountable sample space.
