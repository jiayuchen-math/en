Meaning in context

Given a connection on a smooth vector bundle and a smooth path in its base, the linear map between endpoint fibers that sends an initial vector to the endpoint value of the unique section along the path with zero covariant derivative and that initial value.

给定光滑向量丛上的联络及底空间中的光滑道路，由指定初值且沿道路协变导数为零的唯一截面的终值，定义两端纤维之间的线性映射。

Example

For the Euclidean connection on TR2T\mathbb R^2TR2, a vector with constant Cartesian components remains parallel along any smooth path.

Usage and distinctions

Transport depends on a connection and generally on the whole path, not just its endpoints. A metric-compatible connection preserves inner products, but this is additional to being a connection.
