完全剩余系

Number Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: complete system of residues

Translation evidence: Literature usage

Meaning in context

For m≥1m\ge1m≥1, a set of integers containing exactly one representative of every congruence class modulo mmm.

对正整数 mmm，从每个模 mmm 剩余类恰取一个整数代表所组成的集合。

Example

{−2,−1,0,1,2}\{-2,-1,0,1,2\}{−2,−1,0,1,2} is a complete residue system modulo 555.

Usage and distinctions

Representatives need not lie in the least nonnegative range; the classes, rather than their chosen representatives, are canonical.
