Other names / variants: direct image

Translation evidence: Literature usage

Meaning in context

For f:A→B and S⊆A, the set of values f(s) for s∈S.

对于 f:A→B 和 S⊆A，所有 f(s)（s∈S）构成的集合。

Example

For f(n)=n2f(n)=n^2f(n)=n2, f[{−2,2}]={4}f[\{-2,2\}]=\{4\}f[{−2,2}]={4}.

Usage and distinctions

Images preserve unions but need not preserve intersections when f is not injective.
