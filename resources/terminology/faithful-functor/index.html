忠实函子

Category Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A functor inducing an injective map on each hom-set for a fixed pair of source objects.

对来源范畴任意一对对象，诱导的态射集映射均为单射的函子。

Example

The forgetful functor Vectk→Set\mathbf{Vect}_k\to\mathbf{Set}Vectk​→Set is faithful.

Usage and distinctions

Faithfulness need not distinguish objects; it distinguishes parallel morphisms.
