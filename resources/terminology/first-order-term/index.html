Meaning in context

An expression naming a domain value, built from variables, constants and correctly applied function symbols in a first-order language.

一阶语言中由变元、常数符号和按元数正确使用的函数符号构成、用于指称论域元素的表达式。

Example

f(c)f(c)f(c) is a term when fff is unary and ccc a constant.

Usage and distinctions

Terms denote objects; formulas assert conditions and have truth values after interpretation.
