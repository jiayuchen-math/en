随机图

Combinatorics · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: G(n,p) · Erdős–Rényi G(n,p) model

Translation evidence: Literature usage

Meaning in context

For n ≥ 0 and 0 ≤ p ≤ 1, G(n,p) is the random simple graph on a fixed labeled n-vertex set in which each possible edge is included independently with probability p.

本记录限定 G(n,p) 模型：在固定的 n 个有标号顶点上，每条可能的边独立地以概率 p 出现，其中 n≥0、0≤p≤1。

Example

For G(4,1/2)G(4,1/2)G(4,1/2), the expected number of edges is 6/2=36/2=36/2=3.

Usage and distinctions

The Chinese name 随机图 is broader than this model. G(n,m) fixes the number of edges and generally does not have independent edge indicators.
