模同态

Algebra & Algebraic Geometry · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

An additive map f:M→Nf:M\to Nf:M→N between left RRR-modules satisfying f(rm)=rf(m)f(rm)=rf(m)f(rm)=rf(m).

在同一环的左模之间保持加法与标量作用的映射。

Example

Multiplication by 222 is a Z\mathbb ZZ-module map Z→Z\mathbb Z\to\mathbb ZZ→Z.

Usage and distinctions

The scalar ring must be specified; additive maps are only automatically Z\mathbb ZZ-linear.
