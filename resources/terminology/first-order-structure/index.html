Other names / variants: L-structure

Translation evidence: Literature usage

Meaning in context

A nonempty domain equipped with interpretations of a first-order language’s constants, functions and relations of the prescribed arities.

非空论域连同一阶语言中各常数、函数和关系符号的符合元数的解释。

Example

(Z,0,+,<)(\mathbb Z,0,+,<)(Z,0,+,<) interprets an ordered additive language.

Usage and distinctions

A structure becomes a model of a theory only if it satisfies that theory’s sentences.
