道路连通

Other names / variants: path connectedness

Translation evidence: Literature usage

Meaning in context

A space in which every pair of points is joined by a continuous map from the unit interval.

任意两点都可由从 [0,1][0,1][0,1] 出发的连续道路连接的空间。

Example

A convex subset of Rn\mathbb R^nRn is path connected by straight segments.

Usage and distinctions

Paths may cross themselves and need not be embeddings; path connectedness is stronger than connectedness.
