Other names / variants: function

Translation evidence: Literature usage

Meaning in context

For specified sets A and B, an assignment giving each member of A exactly one member of B.

对于指定的集合 A、B，为 A 的每个元素指定 B 中唯一一个元素的对应。

Example

n↦n+2n\mapsto n+2n↦n+2 defines a map Z→Z\mathbb Z\to\mathbb ZZ→Z.

Usage and distinctions

A formula alone does not specify a function until domain and codomain are stated.
