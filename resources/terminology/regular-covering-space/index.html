Other names / variants: normal covering space

Translation evidence: Literature usage

Meaning in context

A covering map for which the deck-transformation group acts transitively on each fiber, so any two points over the same base point are related by a deck transformation.

复迭映射的每根纤维上，复迭变换群的作用均为传递的，即同一底点上方任意两点可由某个复迭变换相连。

Example

For p:S1→S1p:S^1\to S^1p:S1→S1, p(z)=znp(z)=z^np(z)=zn with n≥1n\geq1n≥1, multiplication by the nth roots of unity gives deck transformations acting transitively on each fiber.

Usage and distinctions

Regularity concerns covering symmetries, not regular topological separation. For path connected coverings over path connected locally path connected bases, it is equivalent to normality of the associated fundamental-group subgroup.
