随机过程

Translation evidence: Literature usage

Meaning in context

An indexed family (Xt)t∈T(X_t)_{t\in T}(Xt​)t∈T​ of random variables or random elements on one probability space, with a specified common state space.

同一概率空间上按指标集合排列、取值于指定状态空间的一族随机变量或随机元素。

Example

Independent coin increments (ξn)n≥1(\xi_n)_{n\ge1}(ξn​)n≥1​ form a discrete-time process; Brownian motion has continuous time.

Usage and distinctions

The time index and the state space can be discrete or continuous independently; an arbitrary process need not have continuous paths.
