狄利克雷 L 函数

Number Theory · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: Dirichlet L-series

Translation evidence: Literature usage

Meaning in context

For a Dirichlet character χ\chiχ, L(s,χ)=∑n≥1χ(n)n−sL(s,\chi)=\sum_{n\ge1}\chi(n)n^{-s}L(s,χ)=∑n≥1​χ(n)n−s for Re⁡s>1\operatorname{Re}s>1Res>1, with its meromorphic continuation.

对狄利克雷特征 χ\chiχ，在 Re⁡s>1\operatorname{Re}s>1Res>1 定义 L(s,χ)=∑n≥1χ(n)n−sL(s,\chi)=\sum_{n\ge1}\chi(n)n^{-s}L(s,χ)=∑n≥1​χ(n)n−s，并取其亚纯延拓。

Example

For the nontrivial character modulo 444, L(2,χ)=1−3−2+5−2−7−2+⋯L(2,\chi)=1-3^{-2}+5^{-2}-7^{-2}+\cdotsL(2,χ)=1−3−2+5−2−7−2+⋯.

Usage and distinctions

A principal character at modulus N gives zeta with the Euler factors at primes dividing N removed; it equals zeta itself only at modulus 1.
