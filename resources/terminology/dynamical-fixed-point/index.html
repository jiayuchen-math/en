不动点

Translation evidence: Literature usage

Meaning in context

For a map T:X→XT:X\to XT:X→X, a point xxx with T(x)=xT(x)=xT(x)=x; for a flow, a point fixed by every time map.

离散映射下作用一次仍为自身的点；对流则要求所有时间映射都固定该点。

Example

The map T(x)=x/2T(x)=x/2T(x)=x/2 has the fixed point 000.

Usage and distinctions

Being fixed by one sampled time map of a flow need not mean equilibrium; a periodic flow orbit may return at that sampling time.
