Meaning in context

The module of tuples from a family (Mi)(M_i)(Mi​) having only finitely many nonzero coordinates, with coordinatewise operations.

模族中仅有有限多个非零坐标的元组所构成的模，运算逐坐标进行。

Example

⨁n≥1Z\bigoplus_{n\ge1}\mathbb Z⨁n≥1​Z consists of finite-support integer sequences.

Usage and distinctions

For an infinite index set the direct product allows infinite support and differs from the direct sum.
