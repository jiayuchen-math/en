Meaning in context

A complete graph K_n, for n ≥ 0, is a simple graph on n vertices with an edge between every pair of distinct vertices.

对 n≥0，完全图 K_n 是任意两个不同顶点都相邻的 n 阶简单图。

Example

K4K_4K4​ has (42)=6\binom42=6(24​)=6 edges.

Usage and distinctions

Complete is stronger than connected; completeness requires direct adjacency, not merely a connecting path.
