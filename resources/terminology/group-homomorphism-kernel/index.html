Meaning in context

For f:G→Hf:G\to Hf:G→H, the subgroup {g:f(g)=eH}\{g:f(g)=e_H\}{g:f(g)=eH​}.

群同态中映到目标群单位元的全部元素组成的子群。

Example

Reduction Z→Z/5Z\mathbb Z\to\mathbb Z/5\mathbb ZZ→Z/5Z has kernel 5Z5\mathbb Z5Z.

Usage and distinctions

Use the target identity, not the empty set or an arbitrarily chosen zero.
