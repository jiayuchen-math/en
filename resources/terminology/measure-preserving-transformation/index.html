Meaning in context

On a measure space (X,B,μ)(X,\mathcal B,\mu)(X,B,μ), a measurable self-map TTT that satisfies μ(T−1A)=μ(A)\mu(T^{-1}A)=\mu(A)μ(T−1A)=μ(A) for all A∈BA\in\mathcal BA∈B.

测度空间上的可测自映射，保持每个可测集合原像的测度。

Example

The doubling map on the circle preserves length although it is not one-to-one.

Usage and distinctions

The transformation need not be invertible; preservation of the image measure of every set is a different assertion.
