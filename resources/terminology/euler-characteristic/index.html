Euler 数

Geometry & Topology · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: Euler示性数

Translation evidence: Literature usage

Meaning in context

For a finite CW complex, the integer obtained by summing the number of cells in each dimension with alternating signs, starting positive in dimension zero; it is independent of the chosen finite cell structure.

对有限 CW 复形，以零维为正号，按维数交错求和各维胞腔数所得的整数；它不依赖所选的有限胞腔结构。

Example

The torus has one zero-cell, two one-cells and one two-cell, so χ(T2)=1−2+1=0\chi(T^2)=1-2+1=0χ(T2)=1−2+1=0. A sphere has one zero-cell and one two-cell, giving 222.

Usage and distinctions

This is an integer invariant, not the Euler cohomology class of a vector bundle. An infinite alternating cell count is not automatically defined; the finite hypothesis is essential here.
