二项式系数

Combinatorics · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: n choose k

Translation evidence: Literature usage

Meaning in context

For integers n ≥ 0 and 0 ≤ k ≤ n, the binomial coefficient counts the k-element subsets of an n-element set and equals n!/(k!(n−k)!). It is defined as zero for integer k outside that range.

对整数 n≥0，二项式系数表示 n 元集合的 k 元子集数；0≤k≤n 时为 n!/(k!(n−k)!)，范围外的整数 k 对应零。

Example

(62)=15\binom{6}{2}=15(26​)=15.

Usage and distinctions

Subset order does not matter; ordered selections have an additional factor k!.
