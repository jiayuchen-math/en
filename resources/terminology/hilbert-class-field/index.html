希尔伯特类域

Translation evidence: Literature usage

Meaning in context

For a number field KKK, its maximal abelian extension unramified at every finite place and split at every real place.

数域 KKK 在所有有限素位非分歧、且所有实素位完全分裂的极大阿贝尔扩张。

Example

The Hilbert class field of Q(i)\mathbb Q(i)Q(i) is Q(i)\mathbb Q(i)Q(i) itself, since its class number is 111.

Usage and distinctions

Requiring real places to split selects the ordinary class field; permitting real places to become complex gives the narrow version used in some conventions.
