合取

Foundations & Logic · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

The connective producing a statement true exactly when both component statements are true.

恰在两个分量命题都为真时为真的联结方式。

Example

(3<4)∧(4<8)(3<4)\land(4<8)(3<4)∧(4<8) is true.

Usage and distinctions

Conjunction requires both components; disjunction in this glossary is inclusive.
