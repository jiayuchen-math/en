Meaning in context

A smooth real-valued function on a smooth manifold whose Hessian at each critical point is a nonsingular symmetric bilinear form; functions with no critical points are included.

光滑流形上的光滑实值函数，其每个临界点处的 Hessian 对称双线性型均非退化；无临界点的函数也满足此定义。

Example

On T2=(R/2πZ)2T^2=(\mathbb R/2\pi\mathbb Z)^2T2=(R/2πZ)2, f(θ,ϕ)=cos⁡θ+2cos⁡ϕf(\theta,\phi)=\cos\theta+2\cos\phif(θ,ϕ)=cosθ+2cosϕ has four nondegenerate critical points with indices 0,1,1,20,1,1,20,1,1,2.

Usage and distinctions

An isolated critical point may still have singular Hessian, as for x4x^4x4 at zero. Morse functions do not require distinct critical values, and their definition does not require a Riemannian metric.
