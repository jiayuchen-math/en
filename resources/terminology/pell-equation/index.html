佩尔方程

Number Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

For a positive nonsquare integer ddd, the equation x2−dy2=1x^2-dy^2=1x2−dy2=1 with integer unknowns x,yx,yx,y.

对正的非平方整数 ddd，以整数 x,yx,yx,y 为未知量的方程 x2−dy2=1x^2-dy^2=1x2−dy2=1。

Example

32−2⋅22=13^2-2\cdot2^2=132−2⋅22=1, so (x,y)=(3,2)(x,y)=(3,2)(x,y)=(3,2) solves the equation for d=2d=2d=2.

Usage and distinctions

Some authors include the negative equation with right side -1 under the same name; this entry fixes the right side as +1.
