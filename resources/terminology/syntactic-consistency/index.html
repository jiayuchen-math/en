一致

Foundations & Logic · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: consistency

Translation evidence: Literature usage

Meaning in context

A sentence set is syntactically consistent in a specified classical calculus if no derivation from it concludes falsity.

对于指定的经典演绎系统，若不能从一个语句集推出矛盾，则称它一致。

Example

{P(c),¬P(c)}\{P(c),\neg P(c)\}{P(c),¬P(c)} is inconsistent.

Usage and distinctions

Consistency is relative to proof rules; satisfiability is semantic. Completeness connects them.
