Other names / variants: closed set

Translation evidence: Literature usage

Meaning in context

A subset whose complement in the specified ambient topological space is open.

在指定拓扑空间中，其补集为开集的子集。

Example

Z\mathbb ZZ is closed in the usual real line.

Usage and distinctions

A set may be both open and closed; closedness is not the negation of openness.
