泛复迭空间

Geometry & Topology · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A covering with path connected and simply connected total space.

总空间道路连通且单连通的复迭空间。

Example

R→S1\mathbb R\to S^1R→S1 is a universal covering.

Usage and distinctions

Existence is guaranteed for path connected, locally path connected, semilocally simply connected bases, not arbitrary spaces.
