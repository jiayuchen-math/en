Meaning in context

Repeatedly replace a nonnegative integer pair (a,b)(a,b)(a,b) with (b,a mod b)(b,a\bmod b)(b,amodb) while b>0b>0b>0; when b=0b=0b=0, the terminal first coordinate aaa is the gcd of the original pair, including gcd⁡(0,0)=0\gcd(0,0)=0gcd(0,0)=0 by convention.

Example

(30,18)→(18,12)→(12,6)→(6,0)(30,18)\to(18,12)\to(12,6)\to(6,0)(30,18)→(18,12)→(12,6)→(6,0) gives gcd 666.

Usage and distinctions

The extended algorithm additionally computes integer linear-combination coefficients; ordinary remainder iteration computes only the gcd.
