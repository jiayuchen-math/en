拓扑空间

Geometry & Topology · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A pair consisting of a set and a family of subsets containing the empty set and the whole set and closed under arbitrary unions and finite intersections.

集合与其开集族组成的二元组；开集族含空集和全集，并对任意并及有限交封闭。

Example

{∅,{a},{a,b}}\{\varnothing,\{a\},\{a,b\}\}{∅,{a},{a,b}} is a topology on {a,b}\{a,b\}{a,b}.

Usage and distinctions

Hausdorff separation and countability are additional axioms, not part of this definition.
