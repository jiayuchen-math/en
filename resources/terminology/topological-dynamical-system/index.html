Translation evidence: Literature usage

Meaning in context

In the discrete-time convention, a pair (X,T)(X,T)(X,T) with a topological space XXX and continuous self-map T:X→XT:X\to XT:X→X, whose evolution is given by the iterates of TTT.

按离散时间约定，由拓扑空间及其连续自映射组成、以该映射的迭代为演化的系统。

Example

The map x↦2x mod 1x\mapsto2x\bmod1x↦2xmod1 defines a topological dynamical system on the circle.

Usage and distinctions

Some authors require a homeomorphism and two-sided time; continuous noninvertible maps are included here.
