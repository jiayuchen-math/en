Meaning in context

An isomorphism of simple graphs G=(V,E) and H=(W,F) is a bijection f:V→W such that uv is in E if and only if f(u)f(v) is in F for each distinct u,v.

简单图 G、H 的同构是顶点间的双射，且两点在 G 中相邻当且仅当对应两点在 H 中相邻。

Example

Relabeling the path a−b−ca-b-ca−b−c as 3−1−23-1-23−1−2 gives an isomorphic graph.

Usage and distinctions

A one-way adjacency-preserving map is not enough; both adjacency and nonadjacency must be preserved by the bijection.
