微分中值定理

Analysis, Measure & PDE · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

If a real function f is continuous on [a,b], differentiable on (a,b), and a<b, some c in (a,b) satisfies f'(c)=(f(b)-f(a))/(b-a).

实函数在非退化闭区间连续且在内部可导，则内部有一点的导数等于两端点函数值之差除以区间长度。

Example

For f(x)=x2f(x)=x^2f(x)=x2 on [1,3][1,3][1,3], the secant slope is 444 and f′(2)=4f'(2)=4f′(2)=4.

Usage and distinctions

The real scalar conclusion does not automatically extend to a vector-valued function with a single common c.
