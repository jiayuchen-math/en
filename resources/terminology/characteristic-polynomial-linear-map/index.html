Translation evidence: Literature usage

Meaning in context

For an endomorphism of an nnn-dimensional FFF-space, the basis-independent monic polynomial det⁡(xI−A)\det(xI-A)det(xI−A).

有限维线性自映射在任一基下的矩阵 AAA 所给出的首一多项式 det⁡(xI−A)\det(xI-A)det(xI−A)。

Example

For A=diag⁡(2,3)A=\operatorname{diag}(2,3)A=diag(2,3) it is (x−2)(x−3)(x-2)(x-3)(x−2)(x−3).

Usage and distinctions

Some sources use det⁡(A−xI)\det(A-xI)det(A−xI); it differs by (−1)n(-1)^n(−1)n from the monic convention here.
