连通图

Combinatorics · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A nonempty finite simple graph is connected when each pair of vertices is joined by a path.

非空有限简单图中，任意两点之间都存在路时，称该图为连通图。

Example

A single vertex with no edges is connected; two isolated vertices are not.

Usage and distinctions

This record excludes the null graph by convention. Connected does not mean complete: a three-vertex path is connected.
