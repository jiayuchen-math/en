半动力系统

Dynamical Systems · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: continuous-time semidynamical system

Translation evidence: Literature usage

Meaning in context

A jointly continuous action ϕ:[0,∞)×X→X\phi:[0,\infty)\times X\to Xϕ:[0,∞)×X→X satisfying ϕ0=id⁡\phi_0=\operatorname{id}ϕ0​=id and ϕt+s=ϕt∘ϕs\phi_{t+s}=\phi_t\circ\phi_sϕt+s​=ϕt​∘ϕs​ for s,t≥0s,t\ge0s,t≥0.

仅用非负实数时间、满足恒同与时间复合律的连续演化；这里取半动力系统的连续时间情形。

Example

On [0,∞)[0,\infty)[0,∞), ϕt(x)=max⁡(x−t,0)\phi_t(x)=\max(x-t,0)ϕt​(x)=max(x−t,0) is a semiflow with noninjective time maps.

Usage and distinctions

The cited Chinese source also allows discrete semigroup time; this record fixes continuous nonnegative time and does not assume reversibility.
