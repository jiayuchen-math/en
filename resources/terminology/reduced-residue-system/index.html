Other names / variants: reduced system of residues

Translation evidence: Literature usage

Meaning in context

For m≥2m\ge2m≥2, a set of integers representing each invertible congruence class modulo mmm exactly once.

对 m≥2m\ge2m≥2，从每个模 mmm 可逆剩余类恰取一个整数代表所组成的集合。

Example

{1,5,7,11}\{1,5,7,11\}{1,5,7,11} is a reduced residue system modulo 121212.

Usage and distinctions

It contains only classes coprime to the modulus, whereas a complete residue system contains every class.
