Meaning in context

A probability-preserving map is weakly mixing if N−1∑n=0N−1∣μ(A∩T−nB)−μ(A)μ(B)∣→0N^{-1}\sum_{n=0}^{N-1}|\mu(A\cap T^{-n}B)-\mu(A)\mu(B)|\to0N−1∑n=0N−1​∣μ(A∩T−nB)−μ(A)μ(B)∣→0 for every measurable A,BA,BA,B.

保概率变换的任意两个固定事件，其相关概率误差的绝对值在时间上的平均趋于0。

Example

A Bernoulli shift is weakly mixing, while an irrational circle rotation is ergodic but not weakly mixing.

Usage and distinctions

The absolute values prevent cancellation; removing them gives an ergodicity criterion rather than weak mixing.
