二部图

Other names / variants: 偶图

Translation evidence: Literature usage

Meaning in context

A simple graph is bipartite if its vertex set admits a partition into two disjoint parts such that every edge has one endpoint in each part.

若简单图的顶点集可分成两个不交部分，且每条边的两端分属两部分，则它是二部图。

Example

A four-cycle is bipartite, with alternating vertices in each part; a triangle is not.

Usage and distinctions

The parts need not have equal size, and vertices within a part have no edges between them. We allow an empty part.
