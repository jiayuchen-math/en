整数的最大公因数

Number Theory · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: gcd · greatest common factor · 最大公约数 · 最大公因子

Translation evidence: Literature usage

Meaning in context

For integers a,ba,ba,b not both zero, the positive common divisor divisible by every common divisor; set gcd⁡(0,0)=0\gcd(0,0)=0gcd(0,0)=0 by convention.

对不全为零的整数 a,ba,ba,b，能被每个公因数整除的正公因数；约定 gcd⁡(0,0)=0\gcd(0,0)=0gcd(0,0)=0。

Example

gcd⁡(252,198)=18\gcd(252,198)=18gcd(252,198)=18.

Usage and distinctions

In a general domain a gcd is only unique up to units; positivity selects a unique integer representative.
