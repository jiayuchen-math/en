Meaning in context

A perfect matching in a finite simple graph is a matching incident with every vertex.

有限简单图中的完美匹配是饱和全部顶点的匹配，即每个顶点恰好属于一条所选边。

Example

In the cycle a−b−c−d−aa-b-c-d-aa−b−c−d−a, {ab,cd}\{ab,cd\}{ab,cd} is a perfect matching.

Usage and distinctions

A matching saturating only one bipartite part is not necessarily perfect. The empty graph has a perfect empty matching by the vacuous convention.
