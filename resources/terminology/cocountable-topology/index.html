余可数拓扑

Translation evidence: Literature usage

Meaning in context

The topology on a set whose open subsets are the empty set together with subsets having at most countable complement; finite complements are allowed.

在集合上，以空集及补集至多可数的子集作为开集的拓扑，其中允许有限补集。

Example

On R\mathbb RR, R∖Q\mathbb R\setminus\mathbb QR∖Q is open in the cocountable topology. It is not open in the cofinite topology because its complement is infinite.

Usage and distinctions

On a countable set this topology is discrete. On an uncountable set it is T1 and any two nonempty opens intersect; it is generally finer than the cofinite topology.
