Meaning in context

For a filtration (Ft)(\mathcal F_t)(Ft​), a random time τ\tauτ valued in [0,∞][0,\infty][0,∞] is a stopping time when {τ≤t}∈Ft\{\tau\le t\}\in\mathcal F_t{τ≤t}∈Ft​ for every ttt.

取非负时间或无穷值的随机时刻；是否已在t时刻之前停止，只依赖于截至t的信息。

Example

For a discrete adapted process XnX_nXn​, inf⁡{n≥0:Xn≥1}\inf\{n\ge0:X_n\ge1\}inf{n≥0:Xn​≥1} is a stopping time.

Usage and distinctions

A last visit before a future deadline generally uses future information; finite-valued stopping times and bounded ones are different restrictions.
