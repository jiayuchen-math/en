Meaning in context

For an integrable real random variable XXX, its expectation is E[X]=∫ΩX dPE[X]=\int_\Omega X\,dPE[X]=∫Ω​XdP; for nonnegative XXX, an extended value +∞+\infty+∞ is allowed.

可积实随机变量关于概率测度的积分；对非负变量可允许结果为正无穷。

Example

If P(X=2)=1/4P(X=2)=1/4P(X=2)=1/4 and P(X=0)=3/4P(X=0)=3/4P(X=0)=3/4, then E[X]=1/2E[X]=1/2E[X]=1/2.

Usage and distinctions

A Cauchy variable has no expectation; its symmetric principal value is not an expectation.
