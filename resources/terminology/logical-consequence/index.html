语义蕴含

Foundations & Logic · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: semantic consequence

Translation evidence: Literature usage

Meaning in context

For a sentence set Γ, a sentence φ is a consequence when every structure satisfying Γ satisfies φ.

对于语句集 Γ，若每个满足 Γ 的结构都满足 φ，则称 Γ 语义蕴含 φ。

Example

{P(c),∀x(P(x)→Q(x))}⊨Q(c)\{P(c),\forall x(P(x)\to Q(x))\}\models Q(c){P(c),∀x(P(x)→Q(x))}⊨Q(c).

Usage and distinctions

⊨ compares truth in structures; ⊢ asserts existence of a derivation.
