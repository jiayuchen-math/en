蕴涵

Foundations & Logic · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: implication

Translation evidence: Literature usage

Meaning in context

The classical connective P→QP\to QP→Q, false exactly when PPP is true and QQQ is false.

经典命题联结词 P→Q；它恰在 P 真且 Q 假时为假。

Example

(2=3)→(5=7)(2=3)\to(5=7)(2=3)→(5=7) is true as a material implication.

Usage and distinctions

A true implication with false antecedent is not evidence of a causal connection.
