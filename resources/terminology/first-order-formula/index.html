合式公式

Foundations & Logic · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: well-formed formula

Translation evidence: Literature usage

Meaning in context

A finite expression of a fixed first-order language built from atomic formulas using its permitted connectives and quantifiers.

在固定一阶语言中，由原子公式按该语言的联结词和量词构成规则生成的有限表达式。

Example

∀x  (P(x)→P(f(x)))\forall x\;(P(x)\to P(f(x)))∀x(P(x)→P(f(x))) is a formula if PPP is unary and fff unary.

Usage and distinctions

An expression with the wrong number of predicate arguments is not well formed.
