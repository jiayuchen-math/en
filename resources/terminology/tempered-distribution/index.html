Meaning in context

A tempered distribution on R^n is a continuous linear functional on Schwartz space with its topology given by all polynomially weighted derivative seminorms.

缓增分布是速降函数空间上的连续线性泛函，连续性须相对于所有多项式加权导数半范数所定义的拓扑。

Example

The constant function 222 defines T(φ)=2∫φT(\varphi)=2\int\varphiT(φ)=2∫φ, bounded by a sufficiently weighted Schwartz seminorm.

Usage and distinctions

Continuity on compactly supported tests defines an ordinary distribution; Schwartz tests impose additional control at infinity.
