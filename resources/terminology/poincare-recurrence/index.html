庞加莱回复定理

Dynamical Systems · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: Poincaré recurrence

Translation evidence: Literature usage

Meaning in context

For a probability-preserving transformation TTT and measurable AAA, almost every x∈Ax\in Ax∈A returns to AAA infinitely often under positive iterates.

保概率系统中，可测集合内几乎所有点在正向迭代下无穷多次返回该集合的定理。

Example

A rotation preserving circle length has almost-everywhere returns to any measurable arc.

Usage and distinctions

Finite total measure is essential for this conclusion; translation on the integers with counting measure can have no returns.
