Other names / variants: topological strong mixing

Translation evidence: Literature usage

Meaning in context

A continuous self-map TTT is topologically mixing when for every nonempty open U,VU,VU,V, some NNN makes Tn(U)∩V≠∅T^n(U)\cap V\ne\varnothingTn(U)∩V=∅ for every n≥Nn\ge Nn≥N.

任意两个非空开区域在所有充分大的迭代时刻均能相连的连续动力系统性质。

Example

The one-sided full binary shift is topologically mixing by concatenating prescribed words with any sufficiently long gap.

Usage and distinctions

It requires every sufficiently late time, not just one time; it says nothing about event probabilities for a chosen measure.
