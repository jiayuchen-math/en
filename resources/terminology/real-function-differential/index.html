Meaning in context

For a function differentiable at a, its differential is the linear map h mapped to f'(a)h in f(a+h)=f(a)+f'(a)h+o(|h|).

实函数在 a 处可微时，展开式中把增量 h 映为 f'(a)h 的线性映射称为微分，其余项相对于 |h| 趋于零。

Example

For f(x)=x2f(x)=x^2f(x)=x2 at a=3a=3a=3, df3(h)=6hdf_3(h)=6hdf3​(h)=6h.

Usage and distinctions

The differential is the linear approximation, not the exact finite increment.
