Translation evidence: Literature usage

Meaning in context

A bounded surjective linear map between Banach spaces sends every open set in its domain to an open set in its codomain.

Banach 空间之间的有界线性满射，把定义域中的每个开集映成值域空间的开集。

Example

T:R2→RT:\mathbb R^2\to\mathbb RT:R2→R, T(x,y)=xT(x,y)=xT(x,y)=x, maps the open unit disk to (−1,1)(-1,1)(−1,1).

Usage and distinctions

Surjectivity is essential: inclusion of a line into R^2 is continuous but its image of an open interval is not open in R^2.
