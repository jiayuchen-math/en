Translation evidence: Literature usage

Meaning in context

A module PPP such that every module map P→CP\to CP→C lifts through every surjective module map B→CB\to CB→C.

到任意模的同态均能沿任意满同态提升的模。

Example

Every free module is projective.

Usage and distinctions

A projective module is a direct summand of a free module, but need not itself be free.
