Meaning in context

A norm on a real or complex vector space is a nonnegative real function N with N(x)=0 exactly for x=0, N(alpha x)=|alpha|N(x), and N(x+y)<=N(x)+N(y).

实或复线性空间上的非负函数，若仅在零向量取零、满足绝对齐次性及三角不等式，则为范数。

Example

∥(x,y)∥1=∣x∣+∣y∣\|(x,y)\|_1=|x|+|y|∥(x,y)∥1​=∣x∣+∣y∣ is a norm and ∥(3,−2)∥1=5\|(3,-2)\|_1=5∥(3,−2)∥1​=5.

Usage and distinctions

A seminorm may vanish on nonzero vectors; squared Euclidean length is not a norm because it scales quadratically.
