Meaning in context

For a discrete random variable with countable support SSS, the function p(x)=P(X=x)p(x)=P(X=x)p(x)=P(X=x) on SSS, whose nonnegative values sum to one.

离散随机变量在各个可能取值处的概率函数，所有非负质量之和为1。

Example

A fair binary variable has p(0)=p(1)=1/2p(0)=p(1)=1/2p(0)=p(1)=1/2.

Usage and distinctions

Mass is point probability; density with respect to length is not point probability.
