紧致性定理

Foundations & Logic · Graduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A set of classical first-order sentences has a model if and only if every finite subset has a model.

经典一阶语句集有模型，当且仅当其每个有限子集有模型。

Example

The axioms c>nˉc>\bar nc>nˉ for all standard nnn, together with arithmetic, have a nonstandard model.

Usage and distinctions

Finite fragments may use different models; the theorem does not force a model on a fixed domain.
