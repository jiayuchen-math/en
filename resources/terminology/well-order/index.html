Translation evidence: Literature usage

Meaning in context

A total order on a set in which every nonempty subset has a least element.

一个全序，其中每个非空子集都有最小元素。

Example

The usual order well-orders N\mathbb NN but not Z\mathbb ZZ.

Usage and distinctions

A least element of the whole set is insufficient; every nonempty subset must have one.
