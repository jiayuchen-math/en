Meaning in context

A continuous map of a metric space is Li–Yorke chaotic when it admits an uncountable set in which every distinct pair satisfies lim inf⁡nd(Tnx,Tny)=0\liminf_n d(T^nx,T^ny)=0liminfn​d(Tnx,Tny)=0 and lim sup⁡nd(Tnx,Tny)>0\limsup_n d(T^nx,T^ny)>0limsupn​d(Tnx,Tny)>0.

存在不可数点集，其中任意不同两点的迭代距离下极限为0且上极限为正的连续系统性质。

Example

The full binary shift admits such a set by interleaving shared zero blocks with repeatedly separated coded blocks.

Usage and distinctions

One scrambled pair is not an uncountable scrambled set; a common positive limsup bound is an additional uniform variant.
