Meaning in context

A commutative unital ring with 1≠01\ne01=0 in which every nonzero element is a unit.

满足 1≠01\ne01=0 且每个非零元素都可逆的交换含幺环。

Example

Z/5Z\mathbb Z/5\mathbb ZZ/5Z is a field.

Usage and distinctions

A division ring need not be commutative; field means commutative here.
