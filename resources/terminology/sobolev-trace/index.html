Meaning in context

For a bounded smooth domain Omega and 1 <= p < infinity, the first-order Sobolev trace is the bounded linear map from W^{1,p}(Omega) to L^p(partial Omega, dS) extending boundary restriction of smooth functions on the closure; its kernel is W^{1,p}_0(Omega).

对有界光滑区域 Ω 及 1≤p<∞，一阶 Sobolev 迹是把闭包上光滑函数的边界限制连续延拓所得的有界线性映射，从 W^{1,p}(Ω) 到边界表面测度下的 L^p(∂Ω)，其核为 W^{1,p}_0(Ω)。

Example

On (0,1)(0,1)(0,1), the trace of u(x)=x(1−x)u(x)=x(1-x)u(x)=x(1−x) is the endpoint pair (0,0)(0,0)(0,0); the trace of the constant function 111 is (1,1)(1,1)(1,1).

Usage and distinctions

This record concerns function boundary values, not operator or matrix trace. Higher-order zero boundary conditions also require derivative traces. The Chinese title is a descriptive qualification of the inspected usage 迹 for Sobolev boundary values, not a claim of normative standardization.
