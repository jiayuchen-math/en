Meaning in context

For an event CCC with P(C)>0P(C)>0P(C)>0, events A,BA,BA,B are independent given CCC when P(A∩B∣C)=P(A∣C)P(B∣C)P(A\cap B\mid C)=P(A\mid C)P(B\mid C)P(A∩B∣C)=P(A∣C)P(B∣C).

当条件事件C的概率为正时，在C所诱导的概率律下交事件概率等于各条件概率之积。

Example

For independent fair bits, conditioning on the bits being equal makes the two 'bit is 1' events dependent: 1/2≠(1/2)21/2\ne(1/2)^21/2=(1/2)2.

Usage and distinctions

Unconditional independence and independence after conditioning do not imply one another; this entry uses event conditioning.
