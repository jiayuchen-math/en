Meaning in context

For a measurable T:X→XT:X\to XT:X→X, a measure μ\muμ is invariant if μ(T−1A)=μ(A)\mu(T^{-1}A)=\mu(A)μ(T−1A)=μ(A) for every measurable set AAA.

对可测变换T，每个可测集合的原像与该集合具有相同测度时，μ称为T的不变测度。

Example

Normalized length on the circle is invariant under rotations and under x↦2x mod 1x\mapsto2x\bmod1x↦2xmod1.

Usage and distinctions

Invariance uses preimages even for noninvertible maps; it does not require every state to be fixed or the measure to be ergodic.
