Other names / variants: vertex chromatic number

Translation evidence: Literature usage

Meaning in context

The chromatic number χ(G) of a finite simple graph is the least nonnegative integer k admitting a vertex coloring with k colors in which adjacent vertices receive different colors.

有限简单图的色数 χ(G) 是允许相邻顶点颜色不同的顶点着色所需的最少颜色数；本记录允许零个颜色用于空图。

Example

χ(C5)=3\chi(C_5)=3χ(C5​)=3, whereas χ(C4)=2\chi(C_4)=2χ(C4​)=2.

Usage and distinctions

This counts vertex colors, not edge colors; an arbitrary Ramsey edge coloring has no proper-coloring requirement.
