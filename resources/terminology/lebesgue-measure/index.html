Meaning in context

Lebesgue measure on R^n is the complete measure obtained by restricting the countable rectangular-cover outer measure to the sets satisfying the Carathéodory splitting criterion.

欧氏空间上的勒贝格测度，是把可数矩形覆盖定义的外测度限制在满足卡拉泰奥多里分割条件的集合上所得的完备测度。

Example

The rectangle [1,3]×[0,4][1,3]\times[0,4][1,3]×[0,4] has measure (3−1)(4−0)=8(3-1)(4-0)=8(3−1)(4−0)=8.

Usage and distinctions

Outer measure is defined for every subset; Lebesgue measure is defined on the Lebesgue sigma-algebra.
