Translation evidence: Literature usage

Meaning in context

An algebraic extension L/KL/KL/K in which every element's minimal polynomial has distinct roots in an algebraic closure.

每个元素在基域上的极小多项式均无重根的代数扩张。

Example

Every algebraic extension in characteristic zero is separable.

Usage and distinctions

An algebraic extension in positive characteristic need not be separable.
