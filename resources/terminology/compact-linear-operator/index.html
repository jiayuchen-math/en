Meaning in context

A linear map between Banach spaces is compact if the image of every bounded set has compact closure in the codomain.

Banach 空间之间的线性映射若把每个有界集映为相对紧集，即其像的闭包紧，则为紧算子。

Example

On ℓ2\ell^2ℓ2, Tx=(xn/(n+1))Tx=(x_n/(n+1))Tx=(xn​/(n+1)) is compact: truncation to n≤Nn\le Nn≤N approximates it in operator norm with error 1/(N+2)1/(N+2)1/(N+2).

Usage and distinctions

A bounded operator need not be compact; the identity on an infinite-dimensional Hilbert space is the basic counterexample.
