态射

Other names / variants: arrow

Translation evidence: Literature usage

Meaning in context

An arrow with a specified source and target in a category, composable with other arrows when their endpoints match.

范畴中有指定来源和目标的箭头；端点相接时可与其他态射合成。

Example

A linear map k2→k3k^2\to k^3k2→k3 is a morphism in Vectk\mathbf{Vect}_kVectk​.

Usage and distinctions

A morphism need not be a set function; an abstract category specifies its own arrows.
