Meaning in context

A sequence of real functions f_n on a common set E converges uniformly to f if for every epsilon > 0 some N makes |f_n(x)-f(x)| < epsilon for all n >= N and all x in E.

同一定义域上的实函数列若对每个正误差都有统一指标，使以后所有函数在每一点的误差均小于该值，则一致收敛。

Usage and distinctions

A pointwise convergence index may depend on x; a uniform index must work over the whole stated domain.
