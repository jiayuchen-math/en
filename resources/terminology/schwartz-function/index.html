Meaning in context

A Schwartz function on R^n is a smooth complex-valued function phi such that sup_x |x^alpha partial^beta phi(x)| is finite for every pair of multi-indices alpha,beta.

速降函数是欧氏空间上的光滑函数，任意阶偏导数乘任意坐标多项式后都保持有界。

Example

φ(x)=e−2x2\varphi(x)=e^{-2x^2}φ(x)=e−2x2 is Schwartz, since each derivative is a polynomial times that Gaussian.

Usage and distinctions

Rapid decay is required for every derivative; ordinary integrability or decay of the function alone is insufficient.
