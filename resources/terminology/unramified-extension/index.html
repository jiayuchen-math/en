Other names / variants: unramified local extension

Translation evidence: Literature usage

Meaning in context

A finite extension L/KL/KL/K of finite extensions of Qp\mathbb Q_pQp​ having ramification index e(L/K)=1e(L/K)=1e(L/K)=1.

Qp\mathbb Q_pQp​ 的有限扩张间的一个分歧指数为 111 的有限扩张 L/KL/KL/K。

Example

Q3(i)/Q3\mathbb Q_3(i)/\mathbb Q_3Q3​(i)/Q3​ is an unramified quadratic extension.

Usage and distinctions

For general complete discretely valued fields, separability of the residue extension is also required; it is automatic for the finite residue fields used here.
