Meaning in context

For a matching M in a finite bipartite graph, an augmenting path is a path of positive length whose edges alternate outside and inside M and whose two endpoints are unmatched; switching membership along it increases matching size by one.

有限二部图中，相对于匹配 M，增广路是长度为正、边交替属于 M 外和 M 内、且两个端点均未匹配的路；沿路切换所选边可使匹配边数增加一。

Example

In a−b−c−da-b-c-da−b−c−d with M={bc}M=\{bc\}M={bc}, the path (a,b,c,d)(a,b,c,d)(a,b,c,d) augments M to {ab,cd}\{ab,cd\}{ab,cd}.

Usage and distinctions

An alternating path with a matched endpoint need not augment. A single edge between unmatched vertices is an augmenting path.
