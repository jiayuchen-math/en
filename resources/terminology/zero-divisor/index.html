零因子

Algebra & Algebraic Geometry · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A nonzero element of a commutative ring whose product with some nonzero element is zero.

交换环中能与某个非零元素相乘得到零的非零元素。

Example

2ˉ\bar22ˉ is a zero divisor in Z/6Z\mathbb Z/6\mathbb ZZ/6Z.

Usage and distinctions

Some authors include zero itself; this record excludes it explicitly.
