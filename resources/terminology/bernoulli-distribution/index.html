Meaning in context

A distribution supported on {0,1}\{0,1\}{0,1} with P(X=1)=pP(X=1)=pP(X=1)=p and P(X=0)=1−pP(X=0)=1-pP(X=0)=1−p, where 0≤p≤10\le p\le10≤p≤1.

取值0和1的分布，其中1的概率为p，0的概率为1−p，且p介于0和1之间。

Example

An event indicator 1A1_A1A​ has Bernoulli distribution with parameter P(A)P(A)P(A).

Usage and distinctions

Bernoulli counts one success indicator; a binomial variable counts successes across a fixed number of independent trials.
