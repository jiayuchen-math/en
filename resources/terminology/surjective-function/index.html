Other names / variants: surjection

Translation evidence: Literature usage

Meaning in context

A function f:A→B whose image is all of B.

像等于整个陪域 B 的映射 f:A→B。

Example

n↦n+2n\mapsto n+2n↦n+2 is surjective on Z\mathbb ZZ.

Usage and distinctions

Surjectivity can change when the codomain changes even if the formula and domain stay fixed.
