Other names / variants: simple path

Translation evidence: Literature usage

Meaning in context

In a simple graph, a path is a finite sequence of distinct vertices whose consecutive pairs are edges; its length is the number of consecutive pairs.

简单图中的路是一个顶点不重复的有限序列，连续两点之间都有边；长度为所用边数。

Example

In the graph with edges ab,bcab,bcab,bc, the sequence (a,b,c)(a,b,c)(a,b,c) is a path of length two.

Usage and distinctions

A walk may repeat vertices; a path may not. This convention admits a one-vertex path of length zero.
