单连通

Translation evidence: Literature usage

Meaning in context

A nonempty path connected space whose fundamental group at one, hence every, basepoint is trivial.

非空道路连通空间，且任一基点处的基本群为平凡群。

Example

SnS^nSn is simply connected for n≥2n\geq2n≥2.

Usage and distinctions

Trivial fundamental groups on each component do not by themselves imply simple connectivity; path connectedness is required.
