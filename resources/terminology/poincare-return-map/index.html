首次返回映射

Dynamical Systems · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Other names / variants: Poincaré map · Poincaré 映射

Translation evidence: Literature usage

Meaning in context

For a flow and a transverse section, the map taking a point to its next positive-time intersection with that section, on the domain where the first return exists.

流的一条横截面上，把有首次正时间返回的点送至其下一次交点的映射。

Example

For unit-speed motion around a circle, a section at one point has return time 111 and identity return map.

Usage and distinctions

A return time must exist; a return map is not generally the time-one map and depends on the section.
