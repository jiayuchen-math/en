线性映射的特征值

Algebra & Algebraic Geometry · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A scalar λ∈F\lambda\in Fλ∈F for which an endomorphism TTT has a nonzero vector vvv with Tv=λvTv=\lambda vTv=λv.

使线性自映射满足 Tv=λvTv=\lambda vTv=λv 且存在非零 vvv 的标量。

Example

diag⁡(2,3)\operatorname{diag}(2,3)diag(2,3) has eigenvalues 2,32,32,3.

Usage and distinctions

The zero vector is never an eigenvector; eigenvalues must belong to the specified field.
