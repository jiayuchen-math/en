Meaning in context

For a self-map TTT, a subset AAA satisfying T(A)=AT(A)=AT(A)=A; this record uses equality rather than only forward inclusion.

自映射把该集合的像恰好变为该集合自身的子集；这里采用像相等的约定。

Example

For T(x)=x2T(x)=x^2T(x)=x2 on [0,1][0,1][0,1], both {0}\{0\}{0} and [0,1][0,1][0,1] are invariant sets.

Usage and distinctions

Forward invariance T(A)subseteqAT(A)subseteq AT(A)subseteqA is weaker for a general map; measurable invariant events in ergodic theory instead use preimages modulo null sets.
