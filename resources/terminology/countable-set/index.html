Meaning in context

A set that is finite or admits a bijection with the natural numbers, including the empty set.

有限或与自然数集之间存在双射的集合；本条约定包括空集。

Example

∅\emptyset∅, N\mathbb NN, and Z\mathbb ZZ are countable; P(N)\mathcal P(\mathbb N)P(N) is not.

Usage and distinctions

Some Chinese and English texts use countable exclusively for the infinite case; this entry includes finite sets.
