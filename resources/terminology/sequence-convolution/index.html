Meaning in context

For sequences (a_n) and (b_n) in a commutative ring indexed by n ≥ 0, their convolution is c_n = ∑{k=0}^n a_k b{n−k}.

从零开始编号的两个交换环值数列，其卷积定义为 c_n=∑{k=0}^n a_k b{n−k}。

Example

Convolving the constant sequences an=bn=1a_n=b_n=1an​=bn​=1 gives cn=n+1c_n=n+1cn​=n+1.

Usage and distinctions

This is discrete ordinary convolution; multiplying EGFs produces binomial-weighted counts instead.
