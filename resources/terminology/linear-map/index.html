线性映射

Algebra & Algebraic Geometry · Undergraduate · Mathematics Resources editorial compilation (AI-assisted)

Translation evidence: Literature usage

Meaning in context

A map T:V→WT:V\to WT:V→W between vector spaces over the same field FFF satisfying T(av+bw)=aT(v)+bT(w)T(av+bw)=aT(v)+bT(w)T(av+bw)=aT(v)+bT(w).

同一域上向量空间之间保持线性组合的映射。

Example

D(a+bx+cx2)=b+2cxD(a+bx+cx^2)=b+2cxD(a+bx+cx2)=b+2cx is real-linear.

Usage and distinctions

Conjugation on C\mathbb CC is real-linear but not complex-linear.
