Meaning in context

The set of every subset of a given set A.

由给定集合 A 的全部子集组成的集合。

Example

P({2})={∅,{2}}\mathcal P(\{2\})=\{\emptyset,\{2\}\}P({2})={∅,{2}}.

Usage and distinctions

Members of a power set are subsets, rather than necessarily members, of A.
