光滑流形的定向

Translation evidence: Literature usage

Meaning in context

On a smooth real n-manifold, an equivalence class of nowhere-vanishing smooth n-forms, where two forms are equivalent when one is a positive smooth function times the other; such a class exists exactly when the manifold is orientable.

在光滑实 nnn 维流形上，处处非零的光滑 nnn 形式的等价类；两形式相差一个正的光滑函数因子时等价。存在这样的等价类当且仅当流形可定向。

Example

On R2\mathbb R^2R2, dx∧dydx\wedge dydx∧dy and exdx∧dye^x dx\wedge dyexdx∧dy define the same orientation; −dx∧dy-dx\wedge dy−dx∧dy defines the opposite orientation.

Usage and distinctions

Orientability is existence of an orientation, whereas orientation is a choice. An orientation fixes signs in integration without selecting the lengths or areas supplied by a metric.
