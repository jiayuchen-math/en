余有限拓扑

Translation evidence: Literature usage

Meaning in context

The topology on a set whose open subsets are the empty set together with subsets having finite complement.

在集合上，以空集及补集为有限集的子集作为开集的拓扑。

Example

On N\mathbb NN, N∖{1,4}\mathbb N\setminus\{1,4\}N∖{1,4} is open. Any two nonempty opens intersect because the union of their finite complements cannot exhaust N\mathbb NN.

Usage and distinctions

On an infinite set this topology is T1 but not Hausdorff. On a finite set it coincides with the discrete topology, so the infinite-set qualification matters.
