Study guide

Build and verify examples by changing one condition, testing domains, and using moving points to expose a quantifier difference.

An example becomes useful when you can explain what it tests. After a new definition, resist filling a notebook with objects that merely have the right name. Choose a question: which condition is doing the work, which familiar operation preserves the property, or where might a tempting converse fail?

For a first experiment, compare subspaces of R2\mathbb R^2R2. The set U={(x,y):x+y=0}U=\{(x,y):x+y=0\}U={(x,y):x+y=0} contains zero and is closed under linear combinations. The parallel line L={(x,y):x+y=1}L=\{(x,y):x+y=1\}L={(x,y):x+y=1} misses zero. That is already a decisive failure, so there is no need to check every subspace axiom for LLL. Moving a line a small distance has preserved its appearance while changing its algebraic status.

Change one feature and keep a record

Write the defining equation, the property being tested, and the decisive calculation. Then make a nearby object. Replace an equality by an inequality, allow an endpoint, or remove a finiteness condition. Change one feature at a time so that the comparison has an explanation.

For instance, x↦x2x\mapsto x^2x↦x2 is continuous on R\mathbb RR but is not uniformly continuous there. Take xn=nx_n=nxn​=n and yn=n+1/ny_n=n+1/nyn​=n+1/n. Their distance tends to zero, while

∣yn2−xn2∣=2+1n2.|y_n^2-x_n^2|=2+\frac{1}{n^2}.∣yn2​−xn2​∣=2+n21​.

Uniform continuity would force these output distances to tend to zero: apply its single δ\deltaδ to both inputs once 1/n<δ1/n<\delta1/n<δ. On a bounded closed interval the same function is uniformly continuous. The domain belongs in the example's name; “the square function” alone leaves out the relevant information.

A failed construction can be informative too. If you seek a continuous function on [0,1][0,1][0,1] that is unbounded, the extreme value theorem rules it out. Record the obstruction. Searching longer will not produce the requested object; changing the domain or dropping continuity might.

Test the quantifiers with a moving point

To distinguish pointwise and uniform convergence, try

fn(x)=nx1+n2x2,0≤x≤1.f_n(x)=\frac{nx}{1+n^2x^2},\qquad 0\leq x\leq1.fn​(x)=1+n2x2nx​,0≤x≤1.

At x=0x=0x=0 the value is zero. At each fixed x>0x>0x>0, dividing numerator and denominator by n2n^2n2 shows convergence to zero. But at the moving point x=1/nx=1/nx=1/n, the value is always 1/21/21/2. Thus the convergence is not uniform. The inequality 2t≤1+t22t\leq1+t^22t≤1+t2 for t≥0t\geq0t≥0 also shows that the supremum is exactly 1/21/21/2.

This example earns its space because it identifies a specific trap: checking each fixed input does not control all inputs at once. Jiří Lebl's Basic Analysis, §6.1, especially §§6.1.2–6.1.3, gives the definitions and uniform norm language needed to state that distinction precisely.

Keep a small collection organized by questions rather than prestige: a map with a large kernel, a continuous function with an inconvenient domain, a sequence whose bad behavior moves. Add enough verification that another reader could check the claim. Ravi Vakil's learning advice, in the opening discussion of learning theory, recommends calculating basic cases. The practical extension here is to keep the calculation attached to the question it resolves.
